# Course guide

This repository is organized around the published course **Time Series Analysis for Environmental Sciences** (course 71106). The official course page describes a practical, hands-on course using environmental datasets, covering data management, data wrangling, visualization, analysis, and forecasting. The outline below is a locally written guide based on the public course page and topic headings; it does not reproduce the instructor's lecture material.

## Learning goals

By the end of the course, students should be able to:

- Explore an environmental time series and formulate useful analysis questions.
- Select suitable tools and methods for those questions.
- Communicate methods and findings through plots, statistics, clear prose, and documented code.

## Topic map

The published site groups its supporting materials into these areas. The brief descriptions are orientation notes, not a substitute for the course lessons.

1. **Getting started** — essential workflow and setup, core Python data and plotting tools, a worked example, and the course's AI-use policy.
2. **Resampling** — working with observations at different time intervals.
3. **Smoothing** — examining broad patterns while reducing short-term variation.
4. **Outliers and gaps** — identifying unusual observations and handling missing intervals thoughtfully.
5. **Stationarity** — considering whether statistical properties are stable over time.
6. **Seasonality** — investigating recurring patterns in environmental observations.
7. **Time lags** — exploring relationships between values at different times.
8. **Frequency** — examining periodic structure in a frequency-based view.
9. **Rates of change** — describing how a measured quantity changes through time.
10. **Forecasting** — using time-series information to make and evaluate predictions.
11. **Homework and technical material** — supporting assignments and practical computing details.
12. **Behind the scenes** — supplementary course material.

The topic titles are taken from the course site's navigation; local notebooks and lessons should be written independently and expanded by the instructor as the syllabus develops.

Confirm assessment details with the instructor if using this guide in a later academic year.
